Instala con un comando

Sin privilegios de administrador y con verificación de integridad SHA-256 antes de ejecutar cualquier binario.

Linux y macOS

bash
$ curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/install.sh | sh

Windows

PowerShell
PS> irm https://github.com/eleodevv/skynative/releases/latest/download/install.ps1 | iex

Desde el código fuente

Go 1.24+
$ git clone https://github.com/eleodevv/skynative.git && cd skynative && make compilar-local

Compilar binarios

make
$ make compilar-todas-plataformas

Un comando

Instalación y desinstalación de un solo paso, con checksum verificado.

Desinstalar

Quita Skynative del sistema cuando ya no lo necesites. Tus proyectos y aplicaciones creadas no se tocan.

Linux y macOS

bash
$ curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/desinstalar.sh | sh

Windows

PowerShell
PS> irm https://github.com/eleodevv/skynative/releases/latest/download/desinstalar.ps1 | iex
