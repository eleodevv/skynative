Del enlace a la ventana

Cuatro pasos, cero andamiaje

Skynative orquesta el entorno de Tauri por ti, de principio a fin.

01 · Crear

Crea

Genera un proyecto Tauri v2 completo (config, iconos y código) a partir de una URL http o https.

02 · Preparar

Prepara

Detecta lo que falta e instala Rust, la CLI de Tauri y las dependencias del sistema pidiendo sudo si hace falta.

03 · Compilar

Compila

Compila automáticamente. Si el empaquetado nativo falla, reintenta con --no-bundle para darte el binario igualmente.

04 · Instalar

Instala

Registra la app con su icono para abrirla con doble clic y encontrarla al buscar. Sin administrador y sin tocar el sistema de más.

Multiplataforma

En todas partes

Linux, macOS y Windows, con el WebView del propio sistema. Binarios pequeños y ligeros.

Seguro por diseño

Sin permisos de más

El contenido remoto no recibe IPC ni acceso al sistema de archivos. Solo se abre la ventana que pediste.
