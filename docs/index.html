Skynative

Convierte una URL en una aplicación de escritorio.

Una herramienta en Go con interfaz de terminal que envuelve cualquier web en una ventana nativa con Tauri v2. Sin plantillas manuales, sin código privilegiado.

Descargar Ver en GitHub

Instalar

Linux · macOS · Windows
$ curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/install.sh | sh
PS> irm https://github.com/eleodevv/skynative/releases/latest/download/install.ps1 | iex

Los instaladores detectan el sistema y la arquitectura, verifican el checksum SHA-256 antes de instalar y no requieren privilegios de administrador. También puedes compilarlo desde el código fuente:

$ git clone https://github.com/eleodevv/skynative.git && cd skynative && make compilar-local

Tras instalar, abre Skynative escribiendo skynative en la terminal. La interfaz se abre sin argumentos; skynative --help muestra la ayuda.

Todo lo demás es una imagen, un título y poco más.

Una URL, una app Genera el proyecto Tauri v2 completo con un formulario guiado.
Explorador integrado Elige la carpeta de salida sin salir de la terminal.
Sin código privilegiado Rechaza esquemas peligrosos y no expone comandos Tauri a la web.
