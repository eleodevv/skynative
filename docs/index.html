Skynative · Tauri v2

Tu web, con un cielo propio.

Convierte una URL en una aplicación de escritorio nativa: ligera, multiplataforma y sin fricción. Skynative la genera, la compila y la deja lista en tu sistema.

Descargar → Ver en GitHub
skynative — zsh
Del enlace a la ventana

Tres pasos para tenerla volando

Sin andamiaje manual. Skynative orquesta todo el entorno de Tauri por ti.

01 · URL

Pega tu URL

Acepta http y https, valida el nombre y rechaza esquemas peligrosos antes de generar nada.

02 · Compilación

Se compila sola

Genera el proyecto Tauri v2, instala lo que falte y compila con Rust y el WebView de tu sistema.

03 · Instalada

Aparece en tu sistema

Registra la app con su icono para abrirla con doble clic y encontrarla al buscar. Sin administrador.

Instalar

Instala con un comando

Elige tu sistema. El instalador verifica el checksum SHA-256 antes de ejecutar nada y no pide administrador.

Linux · terminal 
$ curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/install.sh | sh
macOS · terminal 
$ curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/install.sh | sh
Windows · PowerShell 
PS> irm https://github.com/eleodevv/skynative/releases/latest/download/install.ps1 | iex

Para actualizar, vuelve a ejecutar el instalador: sin variables instala siempre la última release.

Requisitos en Linux

Además de Rust y la CLI de Tauri v2, necesitas las dependencias de escritorio. En Debian o Ubuntu:

sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev \
  build-essential curl wget file libxdo-dev libssl-dev \
  libayatana-appindicator3-dev librsvg2-dev
Requisitos en macOS

Solo las herramientas de línea de comandos de Xcode:

xcode-select --install
Requisitos en Windows

Microsoft Edge WebView2 Runtime (incluido en Windows 10/11) y las herramientas de compilación de Visual Studio (C++ Build Tools).

Tampoco hace falta instalarlos a mano: la opción Instalar herramientas necesarias del menú se encarga por ti.

Uso

Una terminal, todo el vuelo

Skynative vive en tu terminal. Ábrela sin argumentos y deja que el menú te guíe.

$ skynative

Abre el menú interactivo: crear, compilar, instalar, listar y diagnosticar.

$ skynative --help

Muestra la ayuda de la herramienta.

$ skynative --version

Imprime la versión instalada.

Desinstalar

Quítalo cuando quieras

Elimina Skynative del sistema. Tus proyectos y las aplicaciones creadas se quedan intactos.

Linux · macOS · terminal 
$ curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/desinstalar.sh | sh
Windows · PowerShell 
PS> irm https://github.com/eleodevv/skynative/releases/latest/download/desinstalar.ps1 | iex
