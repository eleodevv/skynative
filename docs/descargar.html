Descargar

Instálalo en un instante

Elige tu sistema y pega un comando. El instalador verifica el checksum SHA-256 antes de ejecutar nada y no pide administrador.

$curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/install.sh | sh

$curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/install.sh | sh

PS>irm https://github.com/eleodevv/skynative/releases/latest/download/install.ps1 | iex

Necesitas Rust y la CLI de Tauri v2; el propio menú de Skynative instala lo que falte. Para actualizar, vuelve a ejecutar el instalador.

Desinstalar

Quítalo cuando quieras

Elimina Skynative del sistema. Tus proyectos y las aplicaciones creadas se quedan intactos.

$curl -fsSL https://github.com/eleodevv/skynative/releases/latest/download/desinstalar.sh | sh

PS>irm https://github.com/eleodevv/skynative/releases/latest/download/desinstalar.ps1 | iex
